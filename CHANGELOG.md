# Changelog

All notable changes to the Virex Security project will be documented in this file.

## [v3.0.0] - 2026-07-01
### Added
- **LightGBM ML Engine**: Integrated a highly optimized LightGBM classifier replacing the legacy Random Forest engine.
- **ONNX Runtime Acceleration**: Transpiled the LightGBM models into ONNX graphs for sub-millisecond inferences.
- **Optuna Hyperparameter Tuning**: Dynamically derived optimal `n_estimators`, `learning_rate`, and depth limits using Bayesian Optimization.
- **Centralized Project Quality Reports**: Generated automated JSON metadata and Markdown verification reports for ML pipeline auditing.

### Changed
- **Dashboard Inference Display**: The visualization dashboard now correctly attributes backend ML metrics and logs to `LightGBM`.
- **Dobby Security Bot**: Upgraded both English and Arabic conversational logic to explain security blocks as originating from LightGBM + ONNX architecture.
- **Inference Pipeline Refactoring**: Reworked `backend/app/ml/inference.py` to seamlessly parse integer-key probability dictionaries generated by ONNX models.

### Removed
- **Random Forest Framework**: Wholly purged legacy `.pkl` Random Forest models and one-off training scripts (`build_v2_model.py`, `train_model.py`, etc.).
- **Legacy Serializations**: Dropped legacy `sec_features_v2.pkl` in favor of streamlined LightGBM artifacts.
